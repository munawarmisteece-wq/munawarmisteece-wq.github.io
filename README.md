# Munawar Arif Nitol — portfolio

Live site: https://munawarmisteece-wq.github.io

A single-page portfolio. Everything (HTML, CSS and JavaScript) is in `index.html`; fonts load from Google Fonts. Light green "engineering pad" design with an interactive toy microgrid in the hero: drag the sun to change the time of day, move the cursor quickly to raise the wind, and watch solar, wind, storage and grid trade respond.

## Add a photo

Upload a JPG named `portrait.jpg` next to `index.html` (Add file → Upload files → Commit changes). It appears in the About section automatically. A portrait crop (about 4:5) under 500 KB works best.

## Add a CV

Upload a PDF named `cv.pdf` next to `index.html`. A "Download CV" button then appears in the hero and the contact section automatically.

## Edit text

Open `index.html` on GitHub, click the pencil icon, change the text, then click "Commit changes". The site updates in 1 to 10 minutes. Hard-refresh the page (Ctrl + F5) if you still see the old version.

## When the paper is published

Search `index.html` for "A link to the paper will be added here" and replace that sentence with a link, for example:

```html
<p class="later"><a href="https://doi.org/...">Read the paper in Scientific Reports</a></p>
```
